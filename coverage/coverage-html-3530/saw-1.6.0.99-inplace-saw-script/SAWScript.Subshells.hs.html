    1 {-# LANGUAGE OverloadedStrings #-}
    2 {- |
    3 Module      : SAWScript.Subshells
    4 Description : Find "subshell" and "proof_subshell" usage for special handling
    5 License     : BSD3
    6 Maintainer  : saw@galois.com
    7 Stability   : provisional
    8 
    9 Pass that finds usages of @subshell@ and @proof_subshell@ for
   10 downstream special handling.
   11 
   12 In particular, in order to be able to typecheck what's typed
   13 interactively in a subshell we need to have captured the typing
   14 environment at the point where the subshell is invoked.
   15 
   16 For the time being, the way we do this is by replacing @subshell@ (and
   17 @proof_subshell@) with special-case expressions, and at typechecking
   18 time store a copy of the typing environment in those expressions. The
   19 drawback of this approach is that the expressions appear at the point
   20 where the builtin is mentioned, not where it is actually invoked.
   21 
   22 Because the type of @subshell@ (and comparably @proof_subshell@) in
   23 SAWScript is @() -> TopLevel ()@, two things have to happen after the
   24 builtin is mentioned for it to be actually invoked: someone must apply
   25 a unit argument, and then the resulting value must be monad-bound.
   26 
   27 For soundness, the typing environment on entry to the subshell must
   28 match the value environment. The value environment is captured at the
   29 invocation point, not the mention point. (In principle that could be
   30 changed, but it would be messy and the resulting semantics would be
   31 kind of odd.)
   32 
   33 Therefore, this version rejects uses of @subshell@ and
   34 @proof_subshell@ other than @() <- subshell ()@ or its exact
   35 equivalents. That ensures that, as far as both the typing environment
   36 and value environments are concerned, the capture point is close
   37 enough to the same that the environments will always correspond.
   38 
   39 We have some preexisting cases in the test suite that do things like
   40 
   41 @
   42    do {
   43       let x = 3;
   44       let s = subshell ();
   45       let x = 4;
   46       s;
   47       return ();
   48    };
   49 @
   50 
   51 and check the value of @x@ in the subshell. (It should be 4 and not 3.)
   52 These arose because the historic behavior was extremely squirrelly.
   53 (Some history: #2751, #2306, #2243, #2242.)
   54 
   55 These cases are now rejected.
   56 
   57 Normal usage never does anything like this, and the oddities got
   58 discovered by prodding, not by anyone stepping on them in the field.
   59 Nonetheless, there's at least one reasonable usage that's now
   60 prohibited, namely this function or one like it:
   61 
   62 @
   63    let rebindable use_subshells = true;
   64 
   65    let maybe_subshell () = do {
   66       if use_subshells then
   67          subshell ()
   68       else
   69          return ();
   70    };
   71 @
   72 
   73 This provides a function that conditionally starts a subshell when
   74 monad-bound, in the context of where that monad binding happens.
   75 
   76 Though it's very limited because it has to return the subshell value
   77 out without monad-binding it. This variant, for example, invokes the
   78 subshell from inside the @maybe_subshell@ function, which means it
   79 won't be able to see the caller's context:
   80 
   81 @
   82    let rebindable use_subshells = true;
   83 
   84    let maybe_subshell () = do {
   85       if use_subshells then do {
   86          print "Subshell:";
   87          subshell ();
   88          return ();
   89       }
   90       else
   91          return ();
   92    };
   93 @
   94 
   95 Nonetheless, it's not an entirely unreasonable thing to do. If we
   96 decide that disallowing cases like this that push the subshell value
   97 around before actually invoking it is too restrictive, there is
   98 another approach that should work. However, it's quite a bit more
   99 complicated and at least for now we've decided not to implement it.
  100 It goes as follows.
  101 
  102 Instead of saving the typing environment in special-case expression
  103 nodes, save the typing environment in monad-bind statements. Then
  104 there's a typing environment available in case the monad bind runs a
  105 subshell. To make that work, we'll need to add two new cases of
  106 `Value`: @VSubshell@ and @VProofSubshell@. Make the builtin table
  107 entries point at a `VLambda` of the form @\() -> VSubshell@. Then
  108 applying the unit argument will give the `@VSubshell@` value, and
  109 it'll appear at monad-bind time. In the monad-bind code, check for
  110 @VSubshell@ and @VProofSubshell@ and dispatch them to the actual
  111 subshell code, using the typing environment stored in the monad bind
  112 statement.
  113 
  114 Now, remove the current @Subshell@ and @ProofSubshell@ expressions and
  115 the code for introducing them. Instead, write a conservative static
  116 analysis that decides which monad bind sites might be subshells, and
  117 mark them. Most won't be. Then have the typechecker capture a typing
  118 environment only at the marked cases. This will avoid generating
  119 hundreds or thousands of copies of the typing environment, which is
  120 not a huge data structure but is large enough to be noticeable.
  121 
  122 This alternate approach has at least a couple advantages; for example,
  123 it hardcodes the strings "subshell" and "proof_subshell" in fewer
  124 places, and doesn't require putting placeholder `Value` entries in the
  125 builtins table. But it's markedly more complicated, and there are some
  126 details that will be a headache to sort out, e.g. making stack traces
  127 work right. Plus there's some risk that the above will not interact
  128 correctly with, or interfere with, the monadic/deferred execution
  129 behavior in the interpreter, which is about as robust as a spiderweb
  130 mounted on a clock face.
  131 
  132 Beyond all that there's a further complication, since the most basic
  133 and normal use of @proof_subshell@ is like this:
  134 
  135 @
  136    prove_print (proof_subshell ()) {{ ... }};
  137 @
  138 
  139 which /does not have an actual bind site/ anywhere in SAWScript: it
  140 reduces to a Haskell value of type @ProofScript@ and then that gets
  141 evaluated in the internals, which captures the interpreter's
  142 environment at that point.
  143 
  144 I'm going to deal with this for now by wrapping any subshell found in
  145 an argument position in a do-block. That will result in different
  146 semantics from the prior behavior if the argument is a parameter of a
  147 SAWScript function which explicitly monad-binds that parameter after
  148 doing some other local bindings. I think we will just suck that up.
  149 
  150 -}

  170 ------------------------------------------------------------
  171 -- Support logic
  172 
  173 -- | Type for indicating what we have.
  174 data IsSubshell = IsSubshell | NotSubshell
  175 
  176 -- | Context type for the pass.
  177 --
  178 --   We keep a scoped map that remembers which names have been locally
  179 --   defined. If we see the builtin names we're looking for in this
  180 --   map, they don't actually refer to the builtins and shouldn't be
  181 --   rewritten.
  182 --
  183 --   We also remember if we've already printed the long explanation,
  184 --   so it only comes out once.
  185 data Ctx = Ctx {
  186     ctxShadowed :: IORef (ScopedMap Name Bool),
  187     ctxExplained :: IORef Bool
  188 }
  189 
  190 -- | Create a new context.
  191 newctx :: IO Ctx
  192 newctx = do
  193     shadowed <- IORef.newIORef $ ScopedMap.empty
  194     explained <- IORef.newIORef False
  195     pure $ Ctx { ctxShadowed = shadowed, ctxExplained = explained }
  196 
  197 -- | Enter a new scope.
  198 pushScope :: Ctx -> IO ()
  199 pushScope ctx = do
  200     shadowed <- IORef.readIORef (ctxShadowed ctx)
  201     let shadowed' = ScopedMap.push shadowed
  202     IORef.writeIORef (ctxShadowed ctx) shadowed'
  203 
  204 -- | Leave a scope.
  205 popScope :: Ctx -> IO ()
  206 popScope ctx = do
  207     shadowed <- IORef.readIORef (ctxShadowed ctx)
  208     let shadowed' = ScopedMap.pop shadowed
  209     IORef.writeIORef (ctxShadowed ctx) shadowed'
  210 
  211 -- | Mark a variable as locally defined.
  212 shadow :: Ctx -> Name -> IO ()
  213 shadow ctx x = do
  214     shadowed <- IORef.readIORef (ctxShadowed ctx)
  215     let shadowed' = ScopedMap.insert x True shadowed
  216     IORef.writeIORef (ctxShadowed ctx) shadowed'
  217 
  218 -- | Check if a variable is locally (re)defined.
  219 isShadowed :: Ctx -> Name -> IO Bool
  220 isShadowed ctx x = do
  221     shadowed <- IORef.readIORef (ctxShadowed ctx)
  222     pure $ case ScopedMap.lookup x shadowed of
  223         Nothing -> False
  224         Just t -> t
  225

  228 -- Error handling tools
  229 
  230 -- | Reject an expression
  231 reject :: Ctx -> Expr -> IO Expr
  232 reject ctx e = do
  233     let pos = Pos.getPos e
  234     -- XXX: until we fix up the console handling, errDP will
  235     -- exit, even though it isn't supposed to, and so the explanation
  236     -- doesn't appear.
  237     --errDP pos "Invalid use of subshell"
  238     commentP pos "Error: Invalid use of subshell"
  239     explained <- IORef.readIORef (ctxExplained ctx)
  240     unless explained $ do
  241                  --------------------------------------------------------------------------------
  242         noteN $ "The usage of the \"subshell\" and \"proof_subshell\" builtins is" <>
  243                 " restricted."
  244         noteN $ "In a block or at the top level, use these forms:"
  245         noteN $ "   subshell ();"
  246         noteN $ "   proof_subshell ();"
  247         noteN $ "They may not be the final value of a block."
  248         noteN $ "As a function argument, use these forms:"
  249         noteN $ "   ... (subshell ()) ..."
  250         noteN $ "   ... (proof_subshell ()) ..."
  251         noteN $ "but note that the subshell will run in the caller's context."
  252         IORef.writeIORef (ctxExplained ctx) True
  253     -- XXX: bail out directly. remove when we switch the above back to errDP.
  254     throwIO (Fatal False)
  255 {-
  256     -- return a placeholder expression (doesn't matter what type it
  257     -- is, we'll bail before reaching the typechecker)
  258     pure $ Bool pos False
  259 -}

  265 -- | Process an expression.
  266 --
  267 --   If we see @subshell@ or @proof_subshell@, convert to the
  268 --   special-case version, and mark the return value accordingly.
  269 --
  270 subshell'expr_raw :: Ctx -> Expr -> IO (IsSubshell, Expr)
  271 subshell'expr_raw ctx e0 = case e0 of
  272     Bool{} -> pure (NotSubshell, e0)
  273     String{} -> pure (NotSubshell, e0)
  274     Int{} -> pure (NotSubshell, e0)
  275     Code{} -> pure (NotSubshell, e0)
  276     CType{} -> pure (NotSubshell, e0)
  277     Array pos es -> do
  278         es' <- mapM (subshell'expr ctx) es
  279         pure (NotSubshell, Array pos es')
  280     Block pos (stmts, e1) -> do
  281         -- A block is never a subshell, even though the block might
  282         -- contain one. Don't allow the result value at the end of the
  283         -- block to be a subshell though, as that executes in the
  284         -- parent context rather than the current context.
  285         pushScope ctx
  286         stmts' <- mapM (subshell'stmt ctx) stmts
  287         e1' <- subshell'expr ctx e1
  288         popScope ctx
  289         pure (NotSubshell, Block pos (stmts', e1'))
  290     Tuple pos es -> do
  291         es' <- mapM (subshell'expr ctx) es
  292         pure (NotSubshell, Tuple pos es')
  293     Record pos etbl -> do
  294         etbl' <- traverse (subshell'expr ctx) etbl
  295         pure (NotSubshell, Record pos etbl')
  296     Index pos e1 e2 -> do
  297         e1' <- subshell'expr ctx e1
  298         e2' <- subshell'expr ctx e2
  299         pure (NotSubshell, Index pos e1' e2')
  300     Lookup pos e1 field -> do
  301         e1' <- subshell'expr ctx e1
  302         pure (NotSubshell, Lookup pos e1' field)
  303     TLookup pos e1 field -> do
  304         e1' <- subshell'expr ctx e1
  305         pure (NotSubshell, TLookup pos e1' field)
  306     Var pos x -> do
  307         unshadowed <- not <$> isShadowed ctx x
  308         pure $ case x of
  309             "subshell" | unshadowed ->
  310                 (IsSubshell, Subshell pos emptyAnnotations)
  311             "proof_subshell" | unshadowed ->
  312                 (IsSubshell, ProofSubshell pos emptyAnnotations)
  313             _ ->
  314                 (NotSubshell, Var pos x)
  315     Subshell{} ->
  316         panic "subshell'expr_raw" ["Preexisting Subshell expression"]
  317     ProofSubshell{} ->
  318         panic "subshell'expr_raw" ["Preexisting ProofSubshell expression"]
  319     Lambda pos mname paramPos params namedParams body -> do
  320         pushScope ctx
  321         mapM_ (subshell'pat ctx) params
  322         namedParams' <- do
  323             let once (namepos, (patpos, e, pat)) = do
  324                   -- A default argument value is an unlikely place to
  325                   -- find a subshell, but you never know...
  326                   e' <- subshell'expr ctx e
  327                   subshell'pat ctx pat
  328                   pure $ (namepos, (patpos, e', pat))
  329             traverse once namedParams
  330         body' <- subshell'expr ctx body
  331         popScope ctx
  332         pure (NotSubshell, Lambda pos mname paramPos params namedParams' body')
  333     Application pos e1 args -> do
  334         -- Allow applying args to a subshell. We don't have to check
  335         -- that it's only exactly one unit argument; the typechecker
  336         -- will do that.
  337         (isshell, e1') <- subshell'expr_raw ctx e1
  338         args' <- do
  339             let once (mname, e2) = do
  340                   e2' <- subshell'expr_wrap ctx e2
  341                   pure (mname, e2')
  342             mapM once args
  343         pure (isshell, Application pos e1' args')
  344     Let pos dg e1 -> do
  345         dg' <- subshell'declgroup ctx dg
  346         pushScope ctx
  347         e1' <- subshell'expr ctx e1
  348         popScope ctx
  349         pure (NotSubshell, Let pos dg' e1')
  350     TSig pos e1 ty -> do
  351         -- Allow type signatures on subshell expressions. No real reason
  352         -- not to.
  353         (isshell, e1') <- subshell'expr_raw ctx e1
  354         pure (isshell, TSig pos e1' ty)
  355     IfThenElse pos e1 e2 e3 -> do
  356         e1' <- subshell'expr ctx e1
  357         e2' <- subshell'expr ctx e2
  358         e3' <- subshell'expr ctx e3
  359         pure (NotSubshell, IfThenElse pos e1' e2' e3')
  360 
  361 -- | Process an expression, and wrap it in an implicit do-block if
  362 --   it's a subshell with its unit argument applied. (This is used for
  363 --   applications so passing @proof_subshell@ directly to builtins
  364 --   works as expected.) We don't have to check if the arguments
  365 --   applied are actually just unit; the typechecker does that.
  366 subshell'expr_wrap :: Ctx -> Expr -> IO Expr
  367 subshell'expr_wrap ctx e = do
  368     (isshell, e') <- subshell'expr_raw ctx e
  369     let deny ee = case ee of
  370             Application{} -> False
  371             TSig _ ee' _ -> deny ee'
  372             _ -> True
  373     case isshell of
  374         NotSubshell -> pure e'
  375         IsSubshell
  376           | deny e' -> reject ctx e'
  377           | otherwise -> do
  378               let pos = Pos.getPos e'
  379               let bind = StmtBind pos (PImplicit pos Nothing) e'
  380                   unit = Tuple pos []
  381                   ret = Application pos (Var pos "return") [(Nothing, unit)]
  382               pure $ Block pos ([bind], ret)
  383 
  384 -- | Process an expression, and reject it if it's a subshell.
  385 --   (This is the common case.)
  386 subshell'expr :: Ctx -> Expr -> IO Expr
  387 subshell'expr ctx e = do
  388     (isshell, e') <- subshell'expr_raw ctx e
  389     case isshell of
  390         IsSubshell -> reject ctx e'
  391         NotSubshell -> pure e'
  392 
  393 -- | Process a pattern.
  394 subshell'pat :: Ctx -> Pattern -> IO ()
  395 subshell'pat ctx pat0 = case pat0 of
  396     PImplicit{} -> pure ()
  397     PWild{} -> pure ()
  398     PVar _allpos _xpos x _mty -> shadow ctx x
  399     PTuple _pos pats -> mapM_ (subshell'pat ctx) pats
  400 
  401 -- | Process a declaration group.
  402 subshell'declgroup :: Ctx -> DeclGroup -> IO DeclGroup
  403 subshell'declgroup ctx dg = case dg of
  404     Recursive ds -> do
  405         -- Mutually recursive decls: all the bound names go in scope
  406         -- at once, then after that we inspect all the bodies.
  407         mapM_ (subshell'pat ctx) $ map dPat ds
  408         let once d = do
  409               pushScope ctx
  410               -- rec-binding subshells is not allowed
  411               def' <- subshell'expr ctx $ dDef d
  412               popScope ctx
  413               pure $ d { dDef = def' }
  414         ds' <- mapM once ds
  415         pure $ Recursive ds'
  416     NonRecursive d -> do
  417         subshell'pat ctx $ dPat d
  418         pushScope ctx
  419         -- let-binding subshells is not allowed
  420         def' <- subshell'expr ctx $ dDef d
  421         popScope ctx
  422         let d' = d { dDef = def' }
  423         pure $ NonRecursive d'
  424 
  425 -- | Process a statement.
  426 subshell'stmt :: Ctx -> Stmt -> IO Stmt
  427 subshell'stmt ctx s0 = case s0 of
  428     StmtBind spos pat e -> do
  429         subshell'pat ctx pat
  430         -- Binding subshells is ok.
  431         (_isshell, e') <- subshell'expr_raw ctx e
  432         pure $ StmtBind spos pat e'
  433     StmtLet pos rb dg -> do
  434         dg' <- subshell'declgroup ctx dg
  435         pure $ StmtLet pos rb dg'
  436     StmtCode{} -> pure s0
  437     StmtImport{} -> pure s0
  438     StmtInclude{} -> pure s0
  439     StmtTypedef{} -> pure s0
  440     StmtPushdir{} -> pure s0
  441     StmtPopdir{} -> pure s0
  442

  445 -- External interface
  446 
  447 -- | Run the pass, and return an updated expression.
  448 processExpr :: Expr -> IO Expr
  449 processExpr e = do
  450     ctx <- newctx
  451     e' <- subshell'expr ctx e
  452     checkFail
  453     pure e'
  454 
  455 -- | Run the pass, and return an updated statement list.
  456 processStmts :: [Stmt] -> IO [Stmt]
  457 processStmts stmts = do
  458     ctx <- newctx
  459     stmts' <- mapM (subshell'stmt ctx) stmts
  460     checkFail
  461     pure stmts'
